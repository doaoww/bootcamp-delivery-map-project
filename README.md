## Delivery Planner
 
проект создан в рамках BootCamp 2026, stack: Next.js/React

Сценарий: небольшая компания ежедневно доставляет 20–100 заказов по Алматы. У неё есть несколько курьеров, но маршруты составляются вручную, поэтому курьеры тратят лишнее время и топливо.

приложение, которое автоматически распределяет заказы и рассчитывает эффективные маршруты. еще в процессе
